Network Planner

Privacy

The planner page runs in your browser. Your plan and your theme choice are kept in this browser's local storage so they're still there next time. The plan leaves your device only when you export it. Clearing site data for this page deletes it.

The API checks plans that tools send it. Each request is checked in memory and the result is sent back. Plans aren't stored, and request logging is turned off.

To limit abuse, the API counts requests per IP address for one minute. That count stays in Cloudflare's memory and isn't written anywhere.

The page loads no fonts, scripts or trackers from anywhere else. Cloudflare serves it and handles its traffic under Cloudflare's privacy policy.

Questions: open an issue on GitHub.
