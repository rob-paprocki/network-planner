Network Planner

Privacy

The planner page runs in your browser. Your plan, your theme choice and the map's Colour by setting are kept in this browser's local storage so they're still there next time. The plan leaves your device only when you export it. Clearing site data for this page deletes them.

The API checks plans that tools send it. Each request is checked in memory and the result is sent back. Plans aren't stored, and request logging is turned off.

To limit abuse, the API counts requests per IP address for one minute. That count stays in Cloudflare's memory and isn't written anywhere.

Cloudflare serves the site and adds its Web Analytics script to the page. It counts visits and measures how fast the page loads, using the page address, the referring site and your browser type. It sets no cookies, and it never sees your plan, which stays in your browser. Apart from that script, the page loads no fonts or scripts from anywhere else. Cloudflare handles the site's traffic under Cloudflare's privacy policy.
